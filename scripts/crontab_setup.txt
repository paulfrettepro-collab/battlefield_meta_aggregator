# BF6 Meta Aggregator - Automatisation Hebdomadaire (crontab)
#
# Ce fichier contient les instructions pour configurer l'exécution automatique
# hebdomadaire du pipeline BF6 Meta Aggregator via cron.
#
# Installation:
# 1. Ouvrir crontab: crontab -e
# 2. Copier la ligne ci-dessous (sans le #)
# 3. Sauvegarder et quitter
#
# Vérification:
# - Lister les tâches cron: crontab -l
# - Vérifier les logs: tail -f /Users/paulfrette/Github_pro_folder/battlefield_meta_aggregator/logs/pipeline_*.log

###############################################################################
# OPTION 1: Exécution tous les dimanches à 2h00 du matin
###############################################################################
# 0 2 * * 0 /Users/paulfrette/Github_pro_folder/battlefield_meta_aggregator/scripts/run_pipeline.sh >> /Users/paulfrette/Github_pro_folder/battlefield_meta_aggregator/logs/cron.log 2>&1

###############################################################################
# OPTION 2: Exécution tous les lundis à 3h00 du matin
###############################################################################
# 0 3 * * 1 /Users/paulfrette/Github_pro_folder/battlefield_meta_aggregator/scripts/run_pipeline.sh >> /Users/paulfrette/Github_pro_folder/battlefield_meta_aggregator/logs/cron.log 2>&1

###############################################################################
# OPTION 3: Exécution toutes les semaines (mercredi 1h00)
###############################################################################
# 0 1 * * 3 /Users/paulfrette/Github_pro_folder/battlefield_meta_aggregator/scripts/run_pipeline.sh >> /Users/paulfrette/Github_pro_folder/battlefield_meta_aggregator/logs/cron.log 2>&1
